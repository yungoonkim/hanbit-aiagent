2. 핵심 설계 비결: 왜 파일을 직접 안 보내고 storage_ref를 쓸까요?

에이전트끼리 수십 메가바이트짜리 PDF 파일을 매번 A2A 메시지로 주고받으면 네트워크가 느려지고 LLM의 토큰 한도가 금방 초과됩니다. 그래서 이 프로젝트는 "보관함 열쇠(storage_ref)와 구조화 데이터 상자(DataPart)" 패턴을 사용합니다!

🔑 일상 비유: 무거운 여행 가방 대신 '물품보관함 열쇠(storage_ref)' 건네주기

1. 파일 관리 에이전트(:10013)가 구글 드라이브에서 파일 목록을 찾으면, 파일 본문 대신 gdrive://file/{FILE_ID}라는 고유 열쇠(storage_ref) 목록을 DataPart 아티팩트 상자에 담아 오케스트레이터에게 건넵니다.
2. 오케스트레이터(:10010)는 그 열쇠 목록을 그대로 사내 RAG 에이전트(:10012)에게 전달합니다.
3. 사내 RAG 에이전트(:10012)는 사용자가 원한 파일("하나만" 또는 "전부")의 열쇠만 골라 구글 드라이브에서 직접 다운로드하고 Supabase 벡터 DB에 인덱싱합니다!

폴더: CHAP11_final-project/web_research_agent/ (:10011)

3. 웹 리서치 에이전트: LangChain MCP 어댑터 활용

10장에서는 순수 MCP 클라이언트를 직접 구현했다면, 11장에서는 실무에서 훨씬 간편하게 쓰는 MultiServerMCPClient를 사용하여 Tavily 원격 MCP 서버의 도구를 단 3줄 만에 gemini-3.8-flash 에이전트에 장착합니다.

📄 CHAP11_final-project/web_research_agent/agent.py 포트 10011 
from langchain_google_genai import ChatGoogleGenerativeAI
from langchain_mcp_adapters.client import MultiServerMCPClient

# 1. gemini-3.8-flash 모델 준비
self.model = ChatGoogleGenerativeAI(model="gemini-3.8-flash")

# 2. 원격 Tavily MCP 서버에서 검색 도구 자동 로드 및 에이전트 생성
self.mcp_client = MultiServerMCPClient({
    "tavily": {
        "url": f"https://mcp.tavily.com/mcp/?tavilyApiKey={TAVILY_API_KEY}",
        "transport": "streamable_http",
    }
})
tools = await self.mcp_client.get_tools(server_name="tavily")
self.agent = create_agent(self.model, tools)
폴더: CHAP11_final-project/file_management_agent/ (:10013)

4. 파일 관리 에이전트: Google Drive 8대 도구 & DataPart 반환

Google Drive API(gdrive_client.py)를 감싼 8개의 @tool 함수를 보유하고 있습니다. 특히 파일 목록 조회(list_files)가 실행되면 FileManagementAgentExecutor가 텍스트 답변(TextPart)뿐만 아니라 파일 배열이 담긴 DataPart(name='file_list') 아티팩트도 함께 포장해 줍니다.

폴더: CHAP11_final-project/internal_rag_agent/ (:10012)

5. 사내 지식 RAG 에이전트: 이중 라우팅 LangGraph 아키텍처

InternalRAGAgent는 단순한 검색기를 넘어, 스스로 의도를 판단하는 6개 노드짜리 LangGraph 상태 머신입니다.

START

분기 노드 선택지 언제 선택되나요? (예시)
1차: intent_router search (검색) "휴가 규정 알려줘", "인덱싱된 문서에서 AI 트렌드 찾아줘"
index (인덱싱) "다음 파일들 중 하나만 인덱싱해줘: 보고서.pdf (gdrive://file/abc)"
2차: search_router vector (의미 검색) 문서 본문 내용 질문 ("AI 에이전트 주요 트렌드가 뭐야?") ➡️ match_documents RPC
sql (메타데이터 검색) 파일 형식/이름/날짜 필터 ("PDF 문서만 보여줘", "12월 문서 목록") ➡️ Supabase 테이블 쿼리
